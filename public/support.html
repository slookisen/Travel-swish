Help and support

Keep the app light. Make the trip better.

Quick answers to installation, recommendations and data questions.

Install on iPhone

Open Travel Swipe in Safari, tap Share, choose Add to Home Screen, then confirm. The installed PWA uses the same profile stored in that Safari app context.

Install on Android or Windows

Open the app in Chrome or Edge and select Install app when it appears. The Microsoft Store version is for Windows; the same responsive web app works on iPhone and Android through the browser.

Improve recommendation quality

Choose a destination, answer several varied cards, and use the trip brief to describe who is travelling, pace, budget and discovery style. Use Not relevant on weak results and adjust the taste profile when the learned direction is wrong.

Live search is unavailable

The service may be waking up or a search provider may be temporarily unavailable. Travel Swipe keeps useful starter ideas for experiences and food. Check the notice above the results and retry later for current live places.

Delete your data

Open Taste profile and choose Delete my data. Stay online until the app confirms the backend deletion and reloads.

Report a technical problem

Use the Travel Swipe issue tracker for reproducible bugs and feature suggestions. Do not include private information or your random app user identifier in a public issue. For privacy matters, use the developer contact shown in the Microsoft Store listing.

Norsk

På iPhone: åpne appen i Safari, trykk Del og velg Legg til på Hjem-skjerm. For å slette data går du til Smaksprofil → Slett mine data. Tekniske feil kan meldes i prosjektets issue-tracker, men ikke legg ut private opplysninger eller bruker-ID offentlig.
